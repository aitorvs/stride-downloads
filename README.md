# Stride downloads

[Visit the download page](https://aitorvs.github.io/stride-downloads/)

Stride is a local running journal for Mac and Windows. This public repository
contains the download website and release packages; application development
happens separately.

- [Downloads and release notes](https://github.com/aitorvs/stride-downloads/releases)
- [Report a problem](https://github.com/aitorvs/stride-downloads/issues)

Please don't include Garmin passwords, login tokens, GPS traces, or private
activity exports in public issues.

The website uses plain HTML, CSS, and JavaScript, hosted with GitHub Pages from
`main`. It reads published releases from GitHub's public API; no credentials
are embedded in the website. Draft releases are not displayed.

The first packages are unsigned test builds. See each release's notes before
installing. The website shows a coming-soon state until a release is published.
